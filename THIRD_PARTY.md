# Design and asset attribution

The current presentation is independently implemented with [Yichuan Wang's homepage](https://yichuan-w.github.io/) as a visual reference. That website uses Material for MkDocs; this project does not copy its personal content, custom code, analytics, or images, and does not depend on MkDocs or Material.

The previous supplied template was Haolin Yang's [TidalHarley homepage](https://github.com/TidalHarley/TidalHarley.github.io). Its README credits [d-finite's homepage](https://github.com/d-finite/d-finite.github.io) and [Jon Barron's homepage](https://jonbarron.github.io/) as design sources. It had no top-level site-code license; the earlier attribution and asset notices remain recorded here and in Git history. This project does not relabel that code as MIT.

- Outfit local font retained with the existing assets: SIL Open Font License, included at `assets/fonts/outfit-OFL.txt`. The current presentation uses system fonts.
- GitHub icon: GitHub Octicons, MIT, included at `assets/files/icon/octicons-LICENSE.txt`.
- Email and Google Scholar icons: carried over from the supplied template; their original ownership and branding remain applicable.
- Portrait and publication figures: supplied by Haidong Huang for the existing personal homepage and copied without changing their image contents.
- Institution logos: supplied for the existing homepage; their respective owners retain their rights.
- HH monogram favicon: carried over from the existing personal homepage.

The former academic-homepage code and MIT notice remain available in Git history before this template migration.
